# Getting Started

Welcome to the project documentation.

This GitBook contains the documentation for the project, including its **design, mechanics, development process, and code documentation**.

## GitBook & GitHub

The GitBook is connected to the project's **GitHub repository**

* Documentation can be edited in GitBook or directly in the repository.
* Changes are synchronised between GitBook and GitHub.
* The `gitbook-docs.yaml` file defines the root configuration for the GitBook documentation.

The GitBook documentation is stored in the repository and organised into pages and sections.

## Doxygen

**Doxygen** is used to generate documentation from the project's source code.

While GitBook explains the project from a broader perspective, Doxygen focuses on the **code**, such as:

* Classes and structs
* Functions and methods
* Variables and parameters
* Relationships between code components

The generated Doxygen documentation can be linked from GitBook, its updated directly with the comments in the code.

### Documentation structure

**GitBook** → Project and development documentation
**Doxygen** → Technical code documentation
**GitHub** → Source code and documentation repository
