# Project Overview

## Computer Learner

**Computer Learner** is an educational game designed to teach children aged **5-12** how to use a computer.

The project focuses on practical computer skills through game-based learning, including mouse interaction, keyboard input, basic computer navigation, file management and familiar real-life applications.

## Context

The project is developed for **Game Lab 5: Games for Learning** at **Nord University**.

## Main Goals

The game aims to help children understand computer interaction, practise different mouse and keyboard actions, become familiar with common interfaces and build confidence through guided tasks and feedback.

## Technology

The game is developed using **Unity** and **C#**.

The repository contains the game project, source code and project documentation.
