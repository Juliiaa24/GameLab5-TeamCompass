Detailed Description

A UI target that fires OnHoverComplete after the player keeps the cursor over it for the required duration. Optionally moves around the content area.

This is a child element — it does NOT inherit BaseTask. The parent HoverTargetTask listens to OnHoverComplete and calls Complete().
