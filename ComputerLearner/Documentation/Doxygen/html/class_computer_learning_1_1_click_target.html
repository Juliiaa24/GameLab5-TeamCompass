Detailed Description

A single clickable target circle placed inside a ClickTargetTask. Optionally bounces around the content area for higher difficulties. Reports left-clicks via the OnClicked event.

This is a child element — it does NOT inherit BaseTask. The parent ClickTargetTask listens to OnClicked and calls Complete().
