Detailed Description

Defines a single task: which skill it trains, its difficulty, the prefab to spawn, and the configuration passed to that prefab at runtime.

Create assets under: ScriptableObjects/Tasks/ One asset = one task variant. Different difficulties of the same mechanic are separate assets with different TaskConfig values.
