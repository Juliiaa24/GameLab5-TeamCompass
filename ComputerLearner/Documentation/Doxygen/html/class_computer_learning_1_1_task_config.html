Detailed Description

Data-only configuration that tells a BaseTask prefab how to behave. Stored inside a TaskDefinition ScriptableObject and passed to the task on Initialise().

Add new fields here as new task types require them. Fields that are irrelevant to a specific task type are simply ignored.
